title: "分部职员职责"
---

# 1. 目的

- 明确 VATSIM 中华人民共和国分部（VATPRC）各职员职位的职责范围。
- 规范分部管理工作，明确各部门职权与责任。

# 2. 适用范围

- 本文件适用于 VATPRC 全体分部职员。
- 各职员应按照本文件规定履行职责。

# 3. 职员设置

分部设立以下六个职员职位：

| 职务             | 代号    |
| ---------------- | ------- |
| 分部主席         | VATPRC1 |
| 管制员训练部主管 | VATPRC3 |
| 社区会员部主管   | VATPRC4 |
| 运行部主管       | VATPRC5 |
| 组织部主管       | VATPRC7 |
| 技术部主管       | VATPRC8 |

> 各职位可根据工作需要设置助理职位，由对应职位主管指定并负责管理。

# 4. 一般规定

- 各职员应保持在 VATSIM 的活跃状态。
- 各职员应履行本文件规定的岗位职责，并积极配合其他部门开展工作。
- 各部门主管应定期向分部主席汇报部门工作情况。
- 本文件自公示之日起生效。

# 5. 特殊情况

- 因分部实际运行需要，分部主席可根据具体情况对本文件规定的职责进行临时调整或另行安排。
- 本文件未规定事项，由分部主席负责解释并作出决定。

# 6. 具体职责

## 分部主席（VATPRC1）

- 在 VATSIM 中保持活跃
- 定期举行分部职员会议
- 负责分部的整体平稳运作
- 审核与发布分部政策
- 与其他分部合作，促进国际合作和交流
- 与分部其余成员和职员保持良好沟通
- 每个季度向地区主席提交分部季度报告
- 监控分部下属部门的状态
- 调整管制员等级
- 对分部事务有最终决定权

## 管制员训练部主管（VATPRC3）

- 在 VATSIM 中保持活跃
- 参加分部职员会议，报告部门状态
- 定期向分部主席述职
- 负责制定有利于VATPRC管制员的培训计划
- 维护分部内部管制员权限
- 与管制员教员/教师保持良好沟通，提供管制员专业知识
- 确保持续计划、实施、评估和改进管制员培训计划
- 遵照管制员标准操作程序及管制移交协议书对管制员进行标准训练
- 持续改进适合新人管制员的训练方式和方法
- 定期在部门内举行会议，提出并讨论培训过程中所产生的问题
- 组建管制员教员/教师团队，招募及认证管制员权限
- 监控管制员教员/教师的表现和状态

## 社区会员部主管（VATPRC4）

- 在 VATSIM 中保持活跃
- 参加分部职员会议，报告部门状态
- 定期向分部主席述职
- 快速响应并协调处理成员间的纠纷、反馈与投诉
- 组织开展社群监督与调查工作，确保社群秩序与规则执行
- 协助其他部门开展与会员相关的联合事务
- 对分部事务进行合规性审查

## 运行部主管（VATPRC5）

- 在 VATSIM 中保持活跃
- 参加分部职员会议，报告部门状态
- 定期向分部主席述职
- 管理及制定分部所属空域的运行规则
- 及时了解现实中空域的变化，并视情况对分部空域进行调整
- 视情况发布分部NOTAM，提醒飞行员和管制员分部空域的相关变化
- 制作并维护分部管制员扇区文件
- 与其他分部制定管制移交协议书（LoA）
- 制作并维护管制员标准操作程序（SOP）
- 定期向VATSIM总部提交空域数据

## 组织部主管

- 在 VATSIM 中保持活跃
- 参加分部职员会议，报告部门状态
- 定期向分部主席述职
- 确保分部活动顺利进行
- 负责组织、推广分部活动
- 负责协调与其他分部或组织在分部空域内的活动
- 与其他分部或组织的职员建立联系，为活动提供保障
- 负责活动席位及活动管制员招募
- 持续监控活动情况，及时进行改进
- 维护分部网站的活动板块
- 将活动上传至其余官方平台

## 技术部主管（VATPRC8）

- 在 VATSIM 中保持活跃
- 参加分部职员会议，报告部门状态
- 定期向分部主席述职
- 管理、监控和解决分部运行中存在的信息技术问题
- 设计、维护和改进分部网站和雷达管制系统
- 定期针对分部现存网络资产进行安全审计并向社区会员部主管提供审计报告
- 管理和监控分部官方软件平台
