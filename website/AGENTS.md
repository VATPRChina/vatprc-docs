## Code Style

The project uses React and TanStack Start.

- Prefer using arrow functions, even for React components. Use `React.FC` for the
  type of components.

The project uses both [Mantine UI](https://mantine.dev/) and Tailwind CSS.

- Use Mantine UI components whenever possible, to maintain a consistent UX style.
- Use Tailwind CSS for layout (e.g. flexbox, grid) only.

Use [TanStack Query](https://tanstack.com/query) as the server-state layer. Use
`$api` in `src/lib/client.ts`, which is a strong-typed client generated by `openapi-fetch`.

Use [Lingui](https://lingui.dev/) with React macros for localization.

## Test

Each component should contain a test for rendering each possible state.

Pages should have E2E test with mocked backend.
